## ✨ Features

- 🌍 Dedicated informational pages covering the Solar System planets.
- 🚀 Multiple spaceship options available for selection.
- 🖼️ PHP-based retrieval and display of the selected spaceship's name and image on the next webpage.
- 🌌 Space-inspired backgrounds and custom CSS styling.
- 🪐 Multi-page navigation for a structured browsing experience.
- 📝 User feedback section.

## 🛠️ Technologies Used

- **HTML5** – Webpage structure and content.
- **CSS3** – Visual styling, layouts, backgrounds, and effects.
- **PHP** – Handling spaceship selection and passing selected information to the next webpage for dynamic display.

## 🎯 Learning Outcomes

- Building multi-page websites using HTML.
- Applying CSS for visual design and presentation.
- Understanding PHP and server-side scripting.
- Passing selected data between webpages.
- Dynamically displaying content based on user selection.
