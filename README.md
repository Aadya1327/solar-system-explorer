## ✨ Features

- 🌍 Dedicated informational pages for the planets.
- 🚀 Multiple spaceship options available on the Home page.
- 🖼️ Dynamic retrieval of the selected spaceship's name and image using PHP.
- 🌌 Space-themed backgrounds and visually engaging layouts.
- 🪐 Navigation across multiple webpages.
- 📝 User feedback section.

## 🛠️ Technologies Used

- **HTML5** – Structuring webpages and content.
- **CSS3** – Styling, layouts, backgrounds, and visual effects.
- **PHP** – Handling spaceship selection and dynamically displaying the corresponding name and image.
